帆船启航隐私政策

更新日期：2026年10月8日　生效日期：2026年6月22日

“帆船启航”（以下简称“本应用”）重视用户隐私。本政策说明本应用在提供帆船训练与比赛起航倒计时、定位状态、船速和船头方向显示功能时如何处理信息。

一、处理的信息

本应用仅在用户主动授权后访问设备的精确位置信息和大致位置信息，用于获取定位状态和船速，并在设备本地界面显示。船头方向由设备方向传感器提供；相对风角根据手动设置的风向与设备方向计算，并非自动测量真实风向。

本应用不要求注册或登录，不收集姓名、手机号、通讯录、短信、相册、麦克风、相机、设备标识符、支付信息或广告标识符。

二、权限使用

  • 精确位置：用于通过定位数据获取和显示船速及定位状态。
  • 大致位置：用于在用户仅授予大致位置权限时提供有限的定位状态信息。

用户可以拒绝或在系统设置中撤回位置权限。撤回后，倒计时及其他不依赖定位的功能仍可使用。

三、存储与传输

位置数据仅在设备本地实时处理和显示，不会上传至开发者服务器，不会用于广告、用户画像或营销，也不会向第三方出售、共享或披露。

倒计时状态和用户设置保存在设备本地。卸载应用或清除应用数据后，这些信息将被删除。

四、第三方服务

本应用不集成第三方广告、统计、社交分享、支付或用户行为分析SDK。

五、未成年人保护

本应用面向一般用户，不以未成年人为特定服务对象，也不会主动收集未成年人的个人信息。监护人如发现相关问题，可通过下方联系方式与我们联系。

六、用户权利

由于本应用不将个人信息上传至服务器，开发者不存在可供查询、更正或导出的服务器端用户档案。用户可通过系统权限管理撤回位置权限，也可通过清除应用数据或卸载应用删除本地数据。

七、政策更新

如本应用的功能或信息处理方式发生实质变化，我们会更新本政策，并在应用或发布页面中提示。未经用户另行同意，不会扩大个人信息处理范围。

八、联系我们

如对本政策或个人信息保护有疑问，请通过 GitHub Issues 联系开发者。
